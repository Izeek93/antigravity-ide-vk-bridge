# VK Community Management & Post Scheduling Skill

Инженерное руководство для агентов Antigravity IDE по управлению стеной, беседами модерации и отложенным постингом сообществ ВКонтакте.

---

## 1. Архитектура конвейера публикаций

Система построена по принципу **двухэтапного защищённого конвейера (Two-Stage Gated Pipeline)**:

```
Идея / Контент
      │
      ▼
[1. Генерация драфта] ──► Расчёт таймера (+5ч шаг, ±15м джиттер, пропуск ночи 23:00-09:00)
      │
      ▼
[2. Беседа модерации]  ──► Интерактивная карточка (Inline кнопки)
      │                     ├── [✅ Одобрить]  ──► wall.post (publish_date) ──► Дубликат в хранилище
      │                     ├── [✏️ Доработка] ──► Статус revising, правка на месте (messages.edit)
      │                     └── [❌ Отклонить] ──► Статус rejected, отмена
      ▼
[3. Экстренный отзыв]  ──► Кнопка [🚫 Отозвать] ──► wall.delete (снятие из официального таймера)
```

---

## 2. Ключевые алгоритмические правила

### 2.1. Шаг публикации и джиттер (Anti-Bot Pattern)
1. **Базовый шаг:** 5 часов между постами.
2. **Плавающий джиттер:** `random.randint(-15, +15)` минут.
   * Устраняет строгую минутную регулярность, которую умная лента VK (алгоритм ранжирования 2026) штрафует как подозрительную роботизацию.
3. **Определение базового времени:**
   * Проверяется самый поздний отложенный пост на стене сообщества (`wall.get?filter=postponed`).
   * Следующий пост планируется относительно него, а не относительно текущего момента.

### 2.2. Ночной режим (Тихие часы: 23:00 – 09:00)
* Посты, время которых выпадает на интервал с 23:00 до 09:00, автоматически переносятся на утро следующего дня (в окно 09:00–09:30).
* Публикация в мёртвые ночные часы пессимизирует охваты поста в умной ленте из-за отсутствия первичной реакции аудитории в первые 30 минут.

### 2.3. Редактирование карточек на месте (In-Place Edit)
* При отправке карточки в беседу фиксируется `conversation_message_id` (CMID) через множественный вызов `peer_ids=[target_peer]`.
* При любых доработках черновика бот вызывает `messages.edit` по этому CMID:
  * Лента беседы не захламляется дублирующими сообщениями.
  * Пользователь видит актуальную версию текста, обложки и кнопок в одном и том же сообщении.

## 3. Нативные инструменты FastMCP

Агент в Antigravity IDE может управлять постингом напрямую через вызовы инструментов MCP:

| Инструмент FastMCP | Назначение | Параметры |
| :--- | :--- | :--- |
| `vk_schedule_post` | Создать отложенный черновик и отправить карточку в чат согласования | `title`, `text`, `attachments`, `wall_attachments`, `custom_publish_date`, `peer_id` |
| `vk_list_scheduled_posts` | Просмотреть очередь постов и их статусы | `filter_status` (`pending`, `approved`, `revising`, `rejected`, `recalled`) |
| `vk_recall_scheduled_post` | Отозвать пост из публикации и удалить из таймера стены | `draft_id` |
| `vk_post_to_wall` | Мгновенная публикация на стене сообщества прямо сейчас | `text`, `attachments` |

---

## 4. Программный Python API (`post_scheduler.py`)

Для сценариев пакетной генерации или фоновых скриптов используется Python API:

```python
import post_scheduler

# 1. Создание черновика с автоматическим расчётом времени
draft = post_scheduler.create_and_send_draft(
    title="Полезный лайфхак",
    text="Текст поста...\n\n#хештеги",
    attachments="photo123_456",        # фото для беседы
    wall_attachments="photo-123_456"   # фото для стены сообщества
)
print(f"Черновик {draft['id']} отправлен на согласование на {draft['publish_date_str']}")

# 2. Редактирование черновика на месте (без спама новыми сообщениями)
post_scheduler.update_draft_card(
    draft_id=draft["id"],
    new_text="Обновленный текст поста...\n\n#хештеги",
    new_attachments="photo123_789"
)

# 3. Отзыв черновика или снятие с таймера
post_scheduler.handle_approval_action("post_recall", draft["id"], user_id=0)
```

## 5. Конфигурация окружения (`.env`)

Все параметры настраиваются через переменные окружения:

```env
# Обязательные:
VK_GROUP_TOKEN=vk1.a...          # Токен группы с правами 'messages'
VK_GROUP_ID=123456789            # ID сообщества (число без минуса)

# Опциональные для постинга:
VK_USER_TOKEN=vk1.a...           # Токен пользователя с правами 'photos,wall' (для загрузки обложек на стену)
VK_APPROVALS_PEER_ID=2000000005  # ID беседы согласования черновиков
VK_STORAGE_PEER_ID=2000000006    # ID чата резервного дублирования одобренных постов
VK_POST_FOOTER_TEMPLATE=Больше интересного — [club{group_id}|ТУТ] 💡
```
