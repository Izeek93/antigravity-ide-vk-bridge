# Changelog (Antigravity IDE VK Bridge)

Все значимые изменения проекта **Antigravity IDE VK Bridge** фиксируются в этом документе.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования (SemVer)](https://semver.org/lang/ru/).

---

## [1.1.0] - 2026-09-03

### Added
- **Полная изоляция от других проектов (Zero Coupling):**
  - Очередь `inbox.json` и файл блокировки `inbox.lock` перенесены строго внутрь каталога `vk-bot/`.
  - Устранена любая зависимость от файлов и путей соседнего Telegram-моста.
  - Создано собственное изолированное виртуальное окружение `vk-bot/venv`.
- **Автономный слушатель очереди (`bridge_receiver.py`):**
  - Локальный файловый приёмник для моментального пробуждения агента в IDE без открытых сетевых портов.
  - Защита от коллизий ввода-вывода (`try/except`).
- **Модульный маршрутизатор команд (`command_router.py`):**
  - Изоляция логики команд (`/limits`, `/screen`, `/tasks`, `/voice`, `/status`, `/help`, `/start`).
  - Поддержка интерактивных аппрувов действий в IDE (`/approve`, `/reject`, `да`, `нет`).
- **Универсальный клиент и CLI (`send_vk.py`):**
  - Поддержка отправки сообщений, фотографий, документов и голосовых ответов через CLI.
  - Автоматический сплиттер длинных сообщений (>4000 символов) для соблюдения лимитов VK API.
- **Очистка репозитория:**
  - Удалено более 45 устаревших отладочных скриптов (`send_reply*.py`) и временных медиафайлов.
  - Введена изолированная директория `media/` с автоматической ротацией файлов старше 24 часов.

### Changed
- **Рефакторинг демона `vk_bridge.py`:**
  - Облегчен до чистого транспорта LongPoll.
  - Добавлен порог сетевых ошибок (`consecutive_errors >= 5`) для устранения ложных алертов при кратковременных SSL/HTTP сбоях LongPoll.
- **Очередь сообщений (`queue_manager.py`):**
  - Переведена на `portalocker.Lock` для надёжной межпроцессной OS-level блокировки в Windows.

## [1.0.0] - 2026-08-30

### Added
- Базовый двусторонний LongPoll мост между VK сообществом и Antigravity IDE.
- Локальная транскрибация аудио через Faster-Whisper.
- Синтез речи OmniVoice.
- Интерактивная клавиатура VK.
