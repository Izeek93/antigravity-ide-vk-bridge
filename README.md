---

## 🌟 Возможности

- 💬 **Двусторонний обмен сообщениями:** Прямое общение с агентом Antigravity IDE через сообщения сообщества ВКонтакте.
- ⌨️ **Интерактивная VK-клавиатура:** Быстрые кнопки управления в диалоге (`Лимиты`, `Скриншот`, `Задачи`, `Голос`, `Помощь`).
- 🎙 **Приём голосовых сообщений (STT):** Автоматическая локальная транскрибация аудиосообщений через **Faster-Whisper (CUDA)**.
- 🔊 **Голосовые ответы (TTS):** Генерация аудиосообщений на базе модульного нейро-движка (OmniVoice / Edge-TTS).
- 📸 **Удалённый скриншот экрана (`/screen`):** Мгновенный снимок монитора ПК с отправкой фото в диалог.
- 📊 **Мониторинг квот и процессов (`/limits`, `/tasks`):** Статус активных моделей и фоновых задач.
- 🔒 **Zero-Leak безопасность:** Полная изоляция токенов в `.env` и белый список пользователей `VK_ALLOWED_USER_IDS`.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Заполните параметры:
```ini
VK_GROUP_TOKEN=vk1.a.your_token_here
VK_ALLOWED_USER_IDS=123456789
ENABLE_VOICE_REPLIES=True
```

### 3. Запуск демона моста
```bash
python vk_bridge.py
```

## 🛠 Доступные команды в диалоге VK

| Кнопка / Команда | Описание |
| :--- | :--- |
| `📊 Лимиты` / `/limits` | Телеметрия квот, токенов и лимитов моделей Gemini в IDE |
| `📸 Скриншот` / `/screen` | Снимок экрана рабочего стола компьютера |
| `📋 Задачи` / `/tasks` | Список запущенных фоновых задач и процессов |
| `🎙 Голос` / `/voice` | Переключение голосовых аудиоответов (ВКЛ / ВЫКЛ) |
| `ℹ️ Помощь` / `/help` | Список всех доступных команд и справка |

## 🔒 Безопасность (Zero-Leak Policy)

Проект строго следует политике конфиденциальности:
- Все персональные ключи доступа хранятся исключительно в изолированном локальном файле `.env`.
- Файл `.env` внесён в `.gitignore` и никогда не попадает в Git.
- В репозитории публикуются только обезличенные шаблоны.
